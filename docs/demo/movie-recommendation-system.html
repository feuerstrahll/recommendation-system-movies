Анкета (Cold Start)

  • Выбор любимых жанров
  • Ввод 2–5 любимых фильмов
  • Предпочтение по году: классика / новое / любое
  • Рекомендации через cold_start_score

Hybrid Score

hybrid_score =
  α × svd_score_norm
 + (1−α) × content_score_norm

α управляет балансом между collaborative и content

Переход на коллаб.

  • Коллаборативный фильтр становится доступен после 15 оценок
  • Рекомендации обновляются автоматически после каждого сохранения
  • Стратегия переключается без участия пользователя
Контентная фильтрация
Рекомендации на основе метаданных фильмов

⚙️ Как работает

  • Текстовые эмбеддинги через SentenceTransformer (названия + жанры)
  • Нормализованный год выпуска как числовой признак
  • Интеграция признаков через LightFM (content mode)
  • Implicit feedback: наличие/отсутствие взаимодействия
  • Поиск ближайших соседей через FAISS индекс

✅ Когда использовать

  • Новые пользователи (нет истории)
  • Новые фильмы с малым числом рейтингов
  • Когда нужно объяснить рекомендацию

❌ Ограничения

  • Не учитывает поведение других пользователей
  • Ниже точность при богатой истории

Коллаборативная фильтрация
LightFM — Factorization Machines на взаимодействиях

⚙️ Принцип работы

  • Строит latent embeddings пользователей и фильмов
  • Обучение через WARP loss (Weighted Approximate Rank Pairwise)
  • Explicit ratings → implicit positive/negative feedback
  • Матрица взаимодействий: user × item
  • BPR Loss для ранжирования (положительные выше отрицательных)

✅ Преимущества LightFM

  • Быстрое обучение и инференс
  • Минимум памяти
  • Поддержка side features (метаданные)
  • Простая настройка гиперпараметров
  • Хорошо масштабируется

📄 Модуль: lightfm_model.py

from lightfm import LightFM from lightfm.evaluation import auc_score model = LightFM( no_components=64, loss='warp', learning_rate=0.05 ) model.fit(train, epochs=30, num_threads=4) auc = auc_score(model, test).mean() # → 0.7277
Гибридная система
SVD + FAISS + взвешенное ранжирование

⚙️ Алгоритм

  1. Берём фильмы с оценкой пользователя ≥ 4.0
  2. Строим content-based профиль через FAISS → пул кандидатов
  3. Для кандидатов вычисляем SVD-прогнозы
  4. Итоговый скор = Weighted Hybrid Reranking
hybrid_score =
  α × svd_score_norm
 + (1 − α) × content_score_norm

🎛️ Параметры эксперта

get_hybrid_recommendations( user_id=1, liked_movies=["The Matrix"], alpha=0.6, # баланс SVD/content top_n=10, content_top_k=5000 # FAISS пул )

📊 Поля результата

  • svd_score — оценка SVD
  • content_score — оценка FAISS
  • svd_score_norm — нормализованная
  • content_score_norm — нормализованная
  • hybrid_score — итоговая
GNN — LightGCN
Graph Convolutional Network на графе пользователь–фильм

🕸️ Принцип работы

  • Строит двудольный граф user–item из ratings.csv
  • Инициализирует эмбеддинги случайно, улучшает через K слоёв GCN
  • Пропагирует информацию между соседями (user ↔ item)
  • Обучение через BPR Loss с negative sampling
  • Не использует контентные признаки — только граф связей

⚙️ Параметры

emb_dim = 64 # размер эмбеддинга n_layers = 3 # слоёв GCN lr = 0.001 # learning rate epochs = 20 batch_size = 1024

⚡ Требования

  • PyTorch ≥ 2.0, torch-geometric ≥ 2.3
  • GPU рекомендуется для продакшена

Обоснование выбора для продакшена
Unified Router: LightFM (Hybrid) как основная модель

✅ Почему LightFM + Hybrid

  • ROC AUC 0.7277 — хорошее качество ранжирования
  • Быстрый инференс (~1 сек на CPU)
  • Поддержка cold start через side features
  • Простое переобучение при новых данных
  • Масштабируется без GPU

❌ Почему не LightGCN

  • Требует GPU для продакшена
  • Долгое переобучение (1–3 мин CPU)
  • Сложная инфраструктура (PyG)
  • Ниже объяснимость рекомендаций

🏭 Продакшен-архитектура

  • FastAPI + Gunicorn — serving рекомендаций
  • Redis — кэширование user embeddings
  • FAISS — быстрый поиск похожих фильмов
  • Фоновый переобучение — batch processing
  • Партиционирование ratings по user_id
