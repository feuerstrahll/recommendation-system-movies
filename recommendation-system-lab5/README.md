# Recommendation System Lab 5

Project structure for laboratory work 5 on movie recommendation systems.

## Structure

- `data/raw/` - original datasets.
- `data/processed/` - cleaned and transformed datasets.
- `database/` - SQLite schema, database file, and ER diagram.
- `etl/` - data loading and preprocessing scripts.
- `recommender/` - recommendation algorithms.
- `evaluation/` - quality metrics.
- `report/` - lab report materials.
- `demo.py` - entry point for a small demo.

## Quick Start

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python demo.py
```
