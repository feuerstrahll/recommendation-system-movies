Recommendation Algorithms

🔍

Content-Based

TF-IDF on movie metadata (genres, tags). Cosine similarity to find similar films.

content_based.py
👥

Collaborative

User-user and item-item similarity via rating matrix. Finds users with similar taste.

collaborative.py
🔀

Hybrid

Weighted combination of content-based and collaborative signals for better accuracy.

hybrid.py
💡

All 3 algorithms fully implemented. Live demo via demo.py. Evaluation metrics in evaluation/metrics.py.

Lab 5 · Task 5 — Implemented ✓

Cold Start Solution

🎯 3-Step Onboarding Questionnaire

Q1Select favourite genres (Action, Comedy, Sci-Fi…) — with alias normalization (e.g. "sci-fi" → "Science Fiction")
Q2Name movies you already like — system extracts additional genres from them automatically
Q3Release era preference: old (<2000) / new (≥2000) / both

📐 Cold Start Score Formula

genre_match_score × 0.35
vote_average_norm × 0.30
popularity_norm × 0.25
vote_count_norm × 0.10

🔧 Implementation

questionnaire.py
• recommend_for_new_user()
• normalize_genre_name()
• extract_genres_from_liked()
• apply_release_preference()
• Min-max normalization on all metrics
• Filters movies with <50 votes

📋 Output

Top-10 movies ranked by cold_start_score with: title, release_year, genres, vote_average, popularity, genre_match_score
